# Halvorsen Insights — Monthly Consumer Grocery Tracker: data room

Halvorsen Insights is a fictional consumer-research firm. **All data in this room is synthetic** (generated for a controlled test; there are no real respondents).

The Monthly Consumer Grocery Tracker surveys U.S. adults 18+ each month about grocery shopping behavior and intentions. The headline measure is:

> **pct_online_primary** — percent of respondents who say they plan to do *most* of their grocery shopping online over the next three months.

## Contents

| File | Description |
|---|---|
| `tracker_topline.csv` | Monthly topline: month, unweighted n, pct_online_primary, status (FINAL / PRELIMINARY) |
| `tracker_by_age.csv` | Same measure by age group |
| `bridge_study_2026-02.csv` | Parallel methodology study fielded February 2026 |
