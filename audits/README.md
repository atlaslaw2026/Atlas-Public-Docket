# Representative audits and evaluation

Atlas treats evaluation as a recorded proceeding, not a marketing claim.

**J-0019 — Algorithm Acceptance Audit.** Freeze, broker connectivity, and a HOLD are not acceptance. Labels such as ACCEPTED / OPERATIVE / PROVEN_WORKING require an Algorithm Acceptance Audit.

**J-0020 / J-0021 — Magistrate and objective control.** Material execution must carry purpose and success criteria. The Magistrate is a Goal custodian, not a watcher-overlay copy.

**O-GC-002 / O-GC-004.** Construction and completion accounting: reuse before rebuild; do not declare exhaustion while an authorized path remains.

Detailed MAG files, findings, and run logs that contain private identifiers remain in the private operational record. Public proof here is the *rule* plus the docket status, not a dump of exhibits.
