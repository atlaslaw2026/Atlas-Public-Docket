# Capabilities (public)

Atlas capabilities are registered and discovered through Atlas Room. **Finding a name in a catalog is not proof it is available, tested, or authorized.**

Public-safe examples of capability *classes*:

- Librarian consult / corpus library
- Atlas Room discover / construction intake
- Hunter (authorized source acquisition)
- Magistrate consult
- Deterministic math (code computes; AI may only propose formulas)
- Paper-only execution service (live trading forbidden unless a later public Order says otherwise)
- CRM process-next as a governed lifecycle (send remains standing-false unless granted)

Invocation details that embed private hosts, account IDs, or lead stores are omitted here on purpose.
