# Traceability

Material public changes should be reconstructable as:

**Filing / request → Review → Judgment / Order → Implementation → Commit → Verification → Closure / Pending**

Git history on **this** repository is part of the public docket. It is not a copy of the private operational git history.

Filled examples: [MATTERS.md](MATTERS.md) and [matters.json](matters.json).

Private implementation commits may be cited as `PRIVATE_RETAINED` plus a short change class (for example: “heartbeat is not progress”) without copying private diffs or identifiers.

Do not rewrite authentic history merely to make a timeline prettier. The exception is a documented secret/PII incident (see PUB-M-005).
